Check programming exercises on your own computer

Code-Prüfer is a free desktop application for Windows and macOS that checks programming exercises (Python and Java) locally against test cases.

  • free
  • open source
  • everything stays local
Download Manual (German)

About

Each program runs in an isolated Docker or Podman container without network access, and no code ever leaves the computer. Optional AI features use a local model (llama.cpp) to suggest test cases.

The project is open source under the MIT License. See the Code signing policy for what is signed, the team roles and the privacy policy.

The user interface and the full manual are in German.

The installers are currently not code-signed, so Windows SmartScreen and macOS Gatekeeper warn on first start. On Windows choose “More info” → “Run anyway”; on macOS open System Settings → Privacy & Security → “Open Anyway”. Only do this with a file you downloaded from the official release page yourself.

Requirements: Docker Desktop or Podman. The optional AI needs at least 12 GB of RAM.
