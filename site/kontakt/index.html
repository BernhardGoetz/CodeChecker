Kontakt & Impressum

Über dieses Projekt

Der Code-Prüfer ist ein privates, nicht kommerzielles Open-Source-Projekt. Der Quellcode steht unter der MIT-Lizenz öffentlich auf GitHub.

Kontakt und Anfragen

Fragen, Fehlermeldungen und Wünsche bitte über die Issues auf GitHub. Dafür brauchst du ein kostenloses GitHub-Konto. Bitte schreib dort keine persönlichen Daten hinein, denn Issues sind öffentlich.

Sicherheitslücken melden

Sicherheitslücken bitte nicht als öffentliches Issue melden, sondern vertraulich über GitHub („Private vulnerability reporting“): Sicherheitslücke melden. Wie das genau geht und was als Sicherheitslücke gilt, steht in der Sicherheitsrichtlinie (SECURITY.md).

Datenschutz auf dieser Website

Diese Website liegt bei GitHub (Dienst „GitHub Pages“). Beim Aufruf einer Seite verarbeitet GitHub technisch bedingt Server-Logs, darunter die IP-Adresse deines Geräts. Dafür gilt das GitHub General Privacy Statement.

Die Website selbst setzt keine Cookies, nutzt keine Analyse- oder Tracking-Dienste und lädt keine Inhalte von anderen Servern (keine eingebundenen Schriften, Skripte oder Bilder von Dritten). Links zu anderen Websites, etwa zu GitHub, öffnen sich erst, wenn du sie anklickst.

Wie das Programm selbst mit Daten umgeht, steht in der Privacy policy (englisch) und kurz auf der Startseite.
