Programmieraufgaben automatisch prüfen – direkt auf deinem Computer

So funktioniert es

In drei Schritten von deinem Code zum Ergebnis.

  1. Code eingeben

    Schreib dein Programm in Python oder Java in den Editor oder lade eine Datei hoch. Auf Wunsch fügst du die Aufgabenstellung dazu, auch als Foto, PDF oder Word-Datei.

  2. Testfälle anlegen

    Ein Testfall sagt: „Das tippt jemand ein“ und „das soll das Programm antworten“. Du legst Testfälle selbst an oder lässt dir von der KI welche vorschlagen.

  3. Prüfen

    Ein Klick auf „Prüfen“ startet dein Programm in einem abgeschotteten Bereich ohne Internet. Du siehst für jeden Testfall: bestanden oder nicht, und bei Fehlern genau, was anders war.

Was du brauchst

Zum Prüfen

  • Ein aktuelles Windows 10 oder 11 (64 Bit) oder ein aktuelles macOS (Apple Silicon oder Intel).
  • Docker Desktop (empfohlen) oder Podman. Das Programm startet dein Programm darin, abgeschottet vom restlichen Computer. Unter Windows kann der Installer es auf Wunsch gleich mitinstallieren.
  • Mindestens 8 GB Arbeitsspeicher und etwa 10 GB freier Speicherplatz.
  • Internet nur zum Installieren, für Updates und für das KI-Modell. Zum Prüfen brauchst du kein Internet.

Für die KI (freiwillig)

  • Die KI schlägt Testfälle vor und hilft bei schlecht lesbaren, eingescannten Aufgabenblättern.
  • Sie nutzt das Modell Qwen2.5-Coder 7B und braucht dafür mindestens 12 GB Arbeitsspeicher. Das Modell (ca. 4,4 GB) lädt die App einmalig herunter.
  • Die KI läuft ebenfalls nur auf deinem Computer. Ohne sie funktioniert das Prüfen genauso.
  • Ob dein Code richtig ist, entscheidet immer das tatsächliche Ausführen, nie die KI.

Alle Einzelheiten stehen in der Anleitung unter Systemvoraussetzungen.

Datenschutz in Kürze

  • Dein Code, deine Aufgaben und Testfälle verlassen deinen Computer nie.
  • Es gibt keine Benutzerkonten, keine Nutzungsstatistik und keine Absturzberichte.
  • Ins Internet geht das Programm nur für den Download des KI-Modells, die Suche nach Updates (abschaltbar), das Nachladen der Prüf-Umgebungen, falls nötig, und auf Wunsch für die Installation von Docker Desktop bzw. Podman.
  • Docker Desktop und Podman sind Programme anderer Hersteller und richten sich nach ihren eigenen Einstellungen.

Häufige Fragen

Kostet der Code-Prüfer etwas?

Nein. Das Programm ist kostenlos und Open Source unter der MIT-Lizenz. Du darfst es frei nutzen, verändern und weitergeben.

Wird mein Code ins Internet geschickt?

Nein. Alles läuft auf deinem Computer, auch die KI. Es gibt keinen Server, an den dein Code geht.

Welche Programmiersprachen gehen?

Python und Java. Dein Programm liest Eingaben von der Tastatur (z. B. mit input()) und gibt sein Ergebnis aus (z. B. mit print()). Genau das prüft der Code-Prüfer.

Warum brauche ich Docker oder Podman?

Dein Programm läuft in einem sogenannten Container, einer Art „Mini-Computer im Computer“. Darin hat es kein Internet und kann nichts auf deinem Rechner verändern. Docker Desktop und Podman sind die Programme, die solche Container starten.

Warum warnt Windows beim Installieren?

Der Installer ist noch nicht digital signiert. Windows kennt die Datei deshalb noch nicht und zeigt eine Warnung. Mit „Weitere Informationen“ → „Trotzdem ausführen“ geht es weiter. Mehr dazu: Warum warnt Windows bzw. macOS?

Brauche ich die KI?

Nein. Die KI ist freiwillig und braucht mindestens 12 GB Arbeitsspeicher. Testfälle kannst du immer auch selbst anlegen.

Wird mein Code gespeichert?

Nein. Code, Aufgabe und Testfälle sind weg, wenn du das Programm schließt. Kopiere deinen Code vorher in eine eigene Datei, wenn du ihn behalten willst.

Geht das auf einem Schulrechner?

Für die Installation von Docker Desktop oder Podman braucht man oft Administratorrechte. Auf Schulrechnern hat die nicht jede und jeder. Frag dann bitte deine IT-Betreuung.

Es klappt etwas nicht. Wo finde ich Hilfe?

Viele Lösungen stehen in der Anleitung unter Häufige Probleme und Lösungen. Fehler und Wünsche kannst du als Issue auf GitHub melden.
